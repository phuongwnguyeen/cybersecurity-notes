# Các kiểu dữ liệu

## Integer cơ bản

| Kiểu | Size |
|-------|-------|
| int8_t | 1 byte |
| uint8_t | 1 byte |
| int16_t | 2 byte |
| uint16_t | 2 byte |
| int32_t | 4 byte |
| uint32_t | 4 byte |
| int64_t | 8 byte |
| uint64_t | 8 byte |
| float | 4 byte |
| double | 8 byte |

## Alias hay gặp

| Tên | Bản chất |
|------|-----------|
| BYTE | uint8_t |
| WORD | uint16_t |
| DWORD | uint32_t |
| QWORD | uint64_t |

## Kiểu ký tự / chuỗi

| Kiểu | Ý nghĩa |
|-------|----------|
| char | 1 ký tự |
| char* | Chuỗi |
| wchar_t | Ký tự Unicode |
